### 自动化事实核查与多模态推理前沿文献 (Updates)

* AVERIMATEC: A Dataset for Automatic Verification of Image-Text Claims with Evidence from the Web (NeurIPS 2025)[cite: 2] [[Paper](#)] ![NeurIPS 2025](https://img.shields.io/badge/NeurIPS-2025-blue)
  * **文章内容**：现有的图文核查数据集多为合成数据且缺乏证据注释。[cite: 2] 本文提出了 AVERIMATEC，一个包含1297个真实世界图文声明（image-text claims）的数据集。[cite: 2] 每个声明都标注了包含网络证据的问答（QA）对，以反映核查结果背后的多模态推理过程。[cite: 2]
  * **核心方法**：构建了一个包含声明归一化、时间约束证据标注（以避免时间泄露）和两阶段充分性检查的标注流水线。[cite: 2] 同时，提出了一种基线系统，通过生成用于事实核查的证据搜寻问题，并使用专家工具集（如反向图像搜索、网络文本/图像搜索和视觉问答）来回答这些问题以完成核查。[cite: 2]
  * **个人想法**：将复杂核查任务拆解为QA对并调用专家工具（如VQA、Web Search）的设计非常具有工程落地价值。[cite: 2] 这种模块化的思想非常契合微服务架构，后续在构建多模态核查系统时，可以考虑利用 Spring Boot 等框架将这些检索和视觉问答工具封装成后端 API，让大模型充当调度中心按需调用，从而大幅提升系统的扩展性与执行效率。

* Document-level Claim Extraction and Decontextualisation for Fact-Checking (ACL 2024)[cite: 3] [[Paper](#)] ![ACL 2024](https://img.shields.io/badge/ACL-2024-red)
  * **文章内容**：从包含多个句子的长文档中提取需要核查的声明是一项耗时的任务，而现有方法多局限于句子级别的提取。[cite: 3] 本文提出了一种文档级别的声明提取方法，旨在从长文档中提取值得核查的声明，并对其进行“去语境化（decontextualisation）”，使其在脱离上下文时也能被无歧义地理解。[cite: 3]
  * **核心方法**：首先将声明提取重构为抽取式摘要任务，以识别文档的核心句子。[cite: 3] 然后引入了一个基于问答的框架，通过解答提取句子中的模糊信息单元来获取必要的上下文，并利用 Seq2Seq 模型重写这些句子。[cite: 3] 最后，使用分类器评估去语境化句子的核查价值。[cite: 3]
  * **个人想法**：“去语境化”作为核查的前置步骤切中了实际痛点，未消除指代歧义的文本直接输入模型极易引发事实幻觉。[cite: 3] 在研发 AI 模型训练数据溯源与隐私验证系统时，可以借鉴这种去语境化和核心句抽取的思路，确保上链的声明数据既具备独立语义，又能与原始文档保持严格的逻辑映射。结合零知识证明（ZKP）技术，甚至可以探索如何在不泄露全文隐私的前提下，在链上验证抽取出的去语境化声明的真实来源。
